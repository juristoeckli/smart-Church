# Module Demo

An optional module-authoring playground with examples for registration, saved module state, interactive forms, realtime events, a browser Web Worker for the clock and weather lookup, and a module-owned server worker process. The server worker's status, memory, uptime, and logs are registered through the module SDK and appear in Settings diagnostics. UI, worker processes, styles, and API handlers live in their respective `module-demo` folders. The weather example uses the public Open-Meteo geocoding and forecast APIs; the entered city name is sent to Open-Meteo only after the user submits it. No API key or Smart-Church configuration is required.

Enable **Module Demo** for a location in Settings → Modules.
