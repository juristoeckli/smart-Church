# Personal date and time formats

Each Smart Church user can choose a date and time display preset in **Settings → Personal preferences**. The preference is saved to the user account and follows the user across locations and sign-ins. New and existing accounts default to `DD.MM.YYYY HH:MM`.

Available presets:

- `DD.MM.YYYY HH:MM` — for example, `29.10.2026 14:30` (default)
- `DD/MM/YYYY HH:MM` — for example, `29/10/2026 14:30`
- `MM/DD/YYYY h:mm AM/PM` — for example, `10/29/2026 2:30 PM`
- `YYYY-MM-DD HH:MM` — for example, `2026-10-29 14:30`

The selected preset formats dates shown in Smart Church core pages and built-in modules. Date/time values stored by the API remain in their unambiguous ISO/database formats. Native date and time input controls keep their browser-provided input presentation so values remain easy to enter and validate.
